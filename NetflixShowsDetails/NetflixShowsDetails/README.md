# 🎬 Netflix Show Details (SwiftUI)

An iOS app built with **SwiftUI** that retrieves and displays metadata about Netflix shows using the GraphQL API endpoint.  
The app allows you to **search by Video ID**, fetch metadata, and view details about show.

## 🚀 Features
- **Search field** at the top for entering Netflix **Video ID**  (e.g. 70143830, 70136120, 70153404)
- **Async API integration** with Netflix GraphQL  
- Displays:
  - Show Title & Description  
  - Series / Season / Episode Info  
- **SwiftUI-native UI** with navigation and lists  

---

## 🛠️ Tech Stack
- **Swift 5**  
- **SwiftUI**  
- **MVVM Architecture**  
- **URLSession** for networking  
- **Async/Await** for concurrency
